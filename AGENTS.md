## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout at the repo root. See `docs/agents/domain.md`.

## Commit messages

Use Conventional Commits. Write the subject and body in Japanese after the prefix (e.g. `feat: 認証画面を追加`).
